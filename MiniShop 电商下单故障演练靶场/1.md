可以，按这个顺序来。你现在先做第一阶段联立测试：MiniShop 制造故障，DevOps Agent 接收告警并创建 Incident。先别开 RCA Consumer、LLM、工单这些，等告警链路跑通再开。

1. 准备 DevOps Agent 的 .env

你已经有：

C:\Users\jwk\Desktop\llm\DevOps 智能排障 Agent 平台\.env
确认里面这几项是这样：

DEVOPS_AGENT_APP_ENV=local
DEVOPS_AGENT_DATABASE_URL=postgresql+psycopg://devops:devops@localhost:15432/devops_agent

DEVOPS_AGENT_ALERT_WEBHOOK_AUTH_ENABLED=false

DEVOPS_AGENT_OUTBOX_WORKER_ENABLED=false
DEVOPS_AGENT_RCA_CONSUMER_ENABLED=false
DEVOPS_AGENT_TICKET_SUBMISSION_CONSUMER_ENABLED=false
DEVOPS_AGENT_TICKETING_HTTP_JSON_ENABLED=false
DEVOPS_AGENT_LLM_REPORT_ENABLED=false
DEVOPS_AGENT_ADMIN_OIDC_ENABLED=false
注意：第一阶段不用填 LLM API Key。LLM 是 RCA 报告阶段才用。

2. 启动 PostgreSQL

开一个 PowerShell：

podman run -d --name devops-agent-postgres `
  -e POSTGRES_USER=devops `
  -e POSTGRES_PASSWORD=devops `
  -e POSTGRES_DB=devops_agent `
  -e PGDATA=/var/lib/postgresql/data/pgdata `
  -p 15432:5432 `
  -v "D:\devops-agent-postgres:/var/lib/postgresql/data" `
  postgres:16-alpine
如果之前已经创建过这个容器，就用：

podman start devops-agent-postgres
3. 启动 DevOps Agent 平台

再开一个 PowerShell：

conda activate yolo
cd "C:\Users\jwk\Desktop\llm\DevOps 智能排障 Agent 平台"

python -m pip install uv==0.11.31
uv sync --locked --extra dev
uv run alembic upgrade head
uv run uvicorn main:app --reload --port 8000
检查：

Invoke-RestMethod http://127.0.0.1:8000/healthz
Invoke-RestMethod http://127.0.0.1:8000/readyz
4. 启动 MiniShop

再开一个 PowerShell：

conda activate yolo
cd "C:\Users\jwk\Desktop\llm\DevOps 智能排障 Agent 平台\MiniShop 电商下单故障演练靶场"

python -m pip install uv==0.11.31
uv sync --locked --extra dev
uv run uvicorn app.main:app --reload --port 18080
检查：

Invoke-RestMethod http://127.0.0.1:18080/healthz
5. 联立测试

在 MiniShop 项目目录执行：

cd "C:\Users\jwk\Desktop\llm\DevOps 智能排障 Agent 平台\MiniShop 电商下单故障演练靶场"

python .\scripts\demo_minishop_to_agent.py --agent-url "http://127.0.0.1:8000/api/v1/alerts"
成功时你会看到类似流程：

1. Inject inventory db timeout fault into MiniShop
2. Trigger checkout so the fault becomes visible
3. DevOps Agent alert payload
4. Send alert to DevOps Agent: http://127.0.0.1:8000/api/v1/alerts
   DevOps Agent response status: HTTP 200
这个就说明链路通了：

MiniShop 故障注入
-> checkout 失败
-> 生成告警 payload
-> POST 到 DevOps Agent
-> Agent 接收告警
-> PostgreSQL 落库
-> 创建/关联 Incident
http://127.0.0.1:18080/docs 是 MiniShop 的接口调试台；http://127.0.0.1:8000/docs 是 DevOps Agent 的接口调试台。真正联立靠的是上面的脚本。
